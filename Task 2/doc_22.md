# Лунный клинок

Лунный клинок — один из двух главных мечей сардена. Этот меч выкован из серебра и предназначен для борьбы с чудовищами и нечистью. Лунный металл обладает способностью наносить смертельный урон существам, невосприимчивым к обычной стали. 

Каждый сарден носит лунный клинок на спине, используя его только в бою с монстрами. Клинки часто украшают рунами, улучшающими их магические свойства. Чтобы удерживать меч в идеальном состоянии, сардены регулярно смазывают его маслами, соответствующими типу противника.
