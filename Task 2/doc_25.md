# Пирос

Пирос — знак огня, позволяющий сарденам выпускать пламя из ладони. С помощью этого знака охотники поджигают врагов, создают стену огня или просто разжигают костры. Пирос требует контроля, потому что неосторожное обращение может ранить самого пользователя. 

В битвах Пирос служит для ослабления групп врагов и устрашения чудовищ. Некоторые сардены комбинируют его с маслами и бомбами, усиливая эффект. Тренировка с этим знаком проходит под строгим наблюдением опытных магов.
