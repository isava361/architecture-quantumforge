# Пояснение к базе знаний

Эта база знаний построена на основе статей русскоязычной вики по вселенной «Ведьмака». Для имитации закрытого корпоративного мира все ключевые сущности (имена персонажей, места, события, технологии и организации) были заменены вымышленными названиями.

## Выбор источника

В качестве источника информации использованы статьи из тематической вики, посвящённой «Ведьмаку». Были выбраны страницы о главных героях, второстепенных персонажах, знаках ведьмаков, ведьмачьих школах, магических предметах, мифологических событиях и политических образованиях. Из каждой статьи была извлечена содержательная часть, после чего текст был переформулирован и очищен от служебных элементов.

## Схема переименования

Ключевые термины из исходного канона заменены на вымышленные. Например:

- `Геральт из Ривии` → `Рейнар из Эскалы`
- `Цири` → `Силва`
- `Йеннифэр из Венгерберга` → `Мирелла из Тенесфольда`
- `Трисс Меригольд` → `Лина Варрин`
- `Весемир` → `Ормун`
- `Лютик` → `Баллан`
- `Золтан Хивай` → `Калдор Брот`
- `Эмгыр вар Эмрейс` → `Эмрих вор Амрас`
- `Регис` → `Гавриэль` / `Эмиель Регис` → `Гавриэль Дарнон`
- `Дикстра` → `Мортен Игвар`
- `Вильгефорц` → `Сайридейн`
- `Кейра Мец` → `Вайра Хелин`
- `Филиппа Эйльхарт` → `Далия Норт`
- `Ламберт` → `Галмер`, `Эскель` → `Арвен`, `Кагыр` → `Раен`
- `Каэр Морхен` → `Форт Ламара`
- `Нильфгаард` → `Навмар`
- `Белки` / `Скоя'таэль` → `Теневые Хвосты`
- `Конъюнкция сфер` → `Слияние Реальностей`
- `Дикая Охота` → `Скитающийся Легион`
- `Серебряный меч` → `Лунный клинок`, `Стальной меч` → `Теневой меч`
- Знаки (`Аард`, `Игни`, `Квен`, `Ирден`, `Аксий`) → `Флар`, `Пирос`, `Щилдис`, `Гравий`, `Интус`
- `Мутагены` → `Эволярии`, `Эликсиры` → `Настойки`
- Ведьмачьи школы (`Школа Волка`, `Кота`, `Грифона`, `Медведя`) → `Круг Лисы`, `Круг Феникса`, `Круг Дракона`, `Круг Мантикоры`

Кроме того, было решено заменить само слово «ведьмак» и все его формы на вымышленное название. Это предотвращает связь с оригинальным каноном и делает базу знаний полностью уникальной.

* `Ведьмак` → `Сарден`

Полный словарь замен находится в файле `terms_map.json`.

## Структура

В каталоге находятся 34 текстовых файла (`doc_XX.md`), каждый посвящён отдельной сущности. Названия файлов не совпадают с исходными названиями статей. Тексты описывают историю, характеристики и роль персонажей, организаций, предметов или событий с учётом их новых имён.
