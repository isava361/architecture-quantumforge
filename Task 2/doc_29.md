# Эволярии

Эволярии — мистические вещества, выделенные из органов чудовищ. Сардены добавляют их в настойки и бомбы для усиления эффектов. Каждая эволярия имеет свойства, связанные с чудовищем, из которого она получена: например, из утопца — усиление дыхания под водой, из грифона — улучшение зрения. 

Использование эволяриев требует знаний алхимии и осторожности: неподготовленный организм может быть отравлен. Но для сарденов они — средство выживания, позволяющее превзойти человеческие возможности.
